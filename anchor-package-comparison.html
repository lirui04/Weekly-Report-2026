方案1 减量降币 · 优劣势

优势：
+ 平台招聘币现金支出降幅最大（新签-38%/续费-28%）
+ 伯小乐刊例价大幅提升，引导客户认知伯小乐价值
+ 权益全面缩减，为后续迭代留出空间
+ 新签续费统一刊例价2400，简化定价体系
劣势：
- 新签劲爆职位仅3个（vs 26年5个），客户感知降幅大
- 招聘币面额减600，高依赖客户效果明显下降
- 资源→容器切换，客户可能质疑权益实质变化
- 销售端解释成本高，客户抵触情绪可能较强
适用场景：平台希望最大化降本、对客议价能力强、客户对价格敏感度低于效果敏感度时可优先选方案1

方案2 保职位补币 · 优劣势

优势：
+ 新签劲爆职位保持5个，客户核心权益感知不变
+ 招聘币面额保持2600/2700，客户无直接损失感
+ 同样实现招聘币现金下降（-38%/-28%），降本效果与方案1相同
+ 销售阻力小，客户过渡平稳，续约率影响可控
劣势：
- 续费劲爆职位仍从8降至5（-37.5%），续费客户有感知
- 伯小乐刊例价同样大幅上调，可能引发客户质疑「变相涨价」
- 资源→容器切换同样存在
- 平台「隐性」降本更多（保持面额但降低实际兑现比例）
适用场景：客户敏感度高、续约率为核心KPI、希望平稳过渡减少销售阻力时优先选方案2

策略建议

1. 全国版推荐方案2（保职位补币）： 在招聘币现金降本效果与方案1完全一致的前提下，方案2对客户感知冲击最小。 新签劲爆保持5个、招聘币面额保持2600，销售端可用「权益不变、体系升级」话术平稳过渡。 尤其适合当前招聘市场环境下维护客户续约率。

2. 本地版方案1可接受： 本地版总价直降980元（-25%），对四线及以下城市客户有直接价格吸引力。 权益缩减（劲爆8→5、招聘币-500）在降价背景下客户接受度较高。 建议销售话术强调「总价降了近1000元，核心权益保留」。

3. 资源→容器切换需统一应对： 所有27年方案统一从「资源」切为「容器」，这是客户可能追问的变化点。 建议提前准备标准话术，强调容器模式的灵活性优势（如可自选职位类别等）。

4. 伯小乐刊例价上调需配合价值传递： 伯小乐刊例价从1450/1800大幅上调至2400（全国版），需要在购买页和权益说明中 强化伯小乐的实际效果展示，避免客户产生「变相涨价」的负面感知。
